Exploring when and how friction and smoothness should be used in teaching and learning

This Training Club session explores **friction in learning**. Friction is an obstacle that requires effort to overcome – it can cause discomfort. But when used well, it can be a powerful tool for deepening understanding.

Through a **short presentation and discussions**, we will interrogate when and how friction and smoothness should be used in teaching and learning.

**The session will cover:**

- The difference between friction and smoothness
- Interrogating whether friction should be used
- Discussions on jargon, coding and dyslexia
