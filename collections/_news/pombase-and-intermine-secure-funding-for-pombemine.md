Two of our ELIXIR-UK services, PomBase and InterMine, have received funding for a new collaboration to create a cloud version of the FAIR model organism database PomBase, by using the InterMine platform on the European Open Science Cloud (EOSC)-Life OpenStack. The resulting PombeMine will provide web services and client libraries to enable PomBase data to be used in analytic workflows and a web interface that will allow flexible searching and data export for the fission yeast *Schizosaccharomyces pombe*.

Well done to the teams at the University of Cambridge for their hard work in securing funding for this project.

Visit the web pages of [InterMine](http://intermine.org/) and [PomBase](https://www.pombase.org/) to learn more about these services. You can find a full list of all [ELIXIR-UK services](/services/) on our website.

EOSC-Life has received funding from the European Union’s Horizon 2020 programme under grant agreement number 824087.
