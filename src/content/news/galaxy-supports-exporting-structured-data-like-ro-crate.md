<p><a href="https://galaxyproject.org/">Galaxy</a> is an open-source<a href="https://www.go-fair.org/fair-principles/"> FAIR</a> data analysis platform that enables researchers to use tools from various domains, manage data, run code in interactive environments and more. The majority of the available <a href="https://galaxyproject.org/use/">Galaxy servers</a> are free to use, and open to all.</p>

<p>The new 23.0 release of Galaxy is now live, you can see the release highlights and access the full release notes<a href="https://docs.galaxyproject.org/en/latest/releases/23.0_announce_user.html"> here</a>.</p>

<p>One of the highlights of this release is that Galaxy now offers two options for packaging and publishing workflow artifacts, one is<a href="https://biocomputeobject.org/"> BioCompute Object</a> and the other is<a href="https://www.researchobject.org/ro-crate/"> RO-Crate</a>.</p>

<p>RO-Crate is a community-led effort to define a lightweight method of aggregating and describing research data with associated metadata. It is based on<a href="https://schema.org/"> schema.org</a> annotations in JSON-LD and aims to make formal metadata description best practice accessible and practical for use in a wide range of research situations. RO-Crate is co-led by ELIXIR-UK members and this feature was co-developed by <a href="https://research.manchester.ac.uk/en/persons/soiland-reyes">Stian Soiland-Reyes</a> (University of Manchester).</p>

<p>With this new release, users can directly export valid RO-Crate archive files to any writeable remote file sources that have been configured (e.g., FTP or Dropbox).</p>
