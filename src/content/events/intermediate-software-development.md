<h2 class="wp-block-stackable-divider stk-block-divider stk-block stk-92b1bed" data-block-id="92b1bed">What will you learn?</h2>

<p>This course aims to teach a <strong>core set</strong> of established, intermediate-level software development skills and best practices for working as part of a team in a research environment using Python as an example programming language. The core set of skills we teach is not a comprehensive set of all-encompassing skills but a selective set of tried-and-tested collaborative development skills that form a firm foundation for continuing your learning journey.</p>

<p>Learning objectives:</p>

<ul>
<li>Set up and use a suitable development environment together with popular source code management infrastructure to develop software collaboratively.</li>

<li>Use a test framework to automate the verification of correct behaviour of code and employ parameterisation and continuous integration to scale and further automate code testing.</li>

<li>Design robust, extensible software through the application of suitable programming paradigms and design techniques.</li>

<li>Understand the code review process and employ it to improve the quality of code.</li>

<li>Prepare and release software for reuse by others.</li>

<li>Manage software improvement from feedback through agile techniques.</li>
</ul>

<h2 id="who-is-this-for" class="wp-block-heading">Who is this for?</h2>

<p>A typical learner for this course may be someone who is working in a research environment, needs to write some code, and has gained basi<strong>c software development skills either by self-learning or attending, e.g., a novice Software Carpentry Python course.</strong> They have been <strong>applying those skills in their domain of work by writing code for some time</strong>, e.g. half a year or more. However, their software development-related projects are now becoming larger and are involving more researchers and other stakeholders (e.g. users), for example:</p>

<ul>
<li>Software is becoming more complex, and more collaborative development effort is needed to keep the software running.</li>

<li>Software is going further than just the small group developing and/or using the code - there are more users and an increasing need to add new features.</li>

<li><a href="https://en.wikipedia.org/wiki/Technical_debt">‘Technical debt’</a> is increasing with demands to add new functionality while ensuring previous development efforts remain functional and maintainable.</li>
</ul>

<p>They now need intermediate software engineering skills to help them design more robust software code that goes beyond a few thrown-together proof-of-concept scripts, taking into consideration the lifecycle of software, writing software for stakeholders, team ethic and applying a process to understanding, designing, building, releasing, and maintaining software.</p>

<h2 id="course-prerequisites" class="wp-block-heading"><strong>Course prerequisites </strong></h2>

<p>This course will help you develop your software engineering techniques and learn how to collaborate with others to develop and/or prepare software for others to use. </p>

<p><strong>This course is not accessible to beginners</strong>.</p>

<ul>
<li>You must have experience writing software beyond scripting in a single file to automate a sequence of actions. If you have recently started learning programming, we would expect you to have completed a relevant introductory training course at least 6 months ago. </li>

<li>You must be comfortable with basic Python programming (it doesn’t need to be your main language)</li>

<li>You must know version control using Git and using a command line interface.</li>
</ul>

<p>This workshop aims to cover a significant proportion of the material from a <a href="https://carpentries-incubator.github.io/python-intermediate-development/">Carpentries Incubator course</a>. A more detailed programme will be provided closer to the event.</p>
