<h2><span style="font-weight: 400;">What will you learn?</span></h2>
<span style="font-weight: 400;">This course will introduce the Galaxy Platform, covering the basic functionality for single-cell data processing. It will include an overview of various common single-cell datatypes used in bioinformatics. Participants will gain hands-on experience loading single-cell data from external resources into Galaxy, parsing academic literature to find relevant metadata, and converting the data into the common AnnData format, ready for further analysis in Galaxy.</span>
<h2><span style="font-weight: 400;">Who is this for?</span></h2>
<ul>
 	<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Researchers who want to reuse public single-cell data</span></li>
 	<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Researchers with little to no programming background who would want to use an interface instead of a programming environment</span></li>
</ul>
