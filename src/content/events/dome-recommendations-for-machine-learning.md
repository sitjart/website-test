<p>At this ELIXIR-UK Human Data Community Call, <a href="https://elixiruknode.org/people/tim-beck/" data-type="people" data-id="18652">Tim Beck</a><span style="box-sizing: border-box; margin: 0px; padding: 0px;"> will introduce <a href="https://dome-ml.org/" target="_blank" rel="noopener">DOME</a> guidelines and explain </span>how to apply them to reporting health data machine-learning (ML) analyses.</p>

<p>DOME-ML (or simply DOME) is an acronym standing for Data, Optimization, Model and Evaluation in Machine Learning. DOME is a set of community-wide guidelines, recommendations, and checklists spanning these four areas that help establish supervised machine learning validation standards in biology. The recommendations are formulated as questions to anyone wishing to pursue the implementation of a machine learning algorithm. Answers to these questions can be easily included in the supplementary material of published papers.<br></p>
