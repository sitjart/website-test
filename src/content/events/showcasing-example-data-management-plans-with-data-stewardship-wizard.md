<p>At the July 2025 RDM Club Call, we will showcase work from the <a href="https://elixiruknode.org/activities/fellowship/">ELIXIR-UK DaSH Fellowship</a> and <a href="https://biofair.uk/">BioFAIR</a>, which brings together user stories and RDM tools to support FAIR data management. This collaborative effort, driven by data stewards and research software engineers (RSEs) from 10 UK research-performing organisations, features 17 example data management plans (DMPs) and a collection of guidance videos covering a wide range of Life Sciences data types.</p>

<p>We will also share user stories highlighting the use of the <a href="https://ds-wizard.org/">Data Stewardship Wizard</a> (DSW), a DMP management tool officially recommended by the <a href="https://ec.europa.eu/info/funding-tenders/opportunities/docs/2021-2027/horizon/guidance/programme-guide_horizon_en.pdf">Horizon Europe Programme Guide</a>. These stories demonstrate how the tool can be locally hosted and tailored to suit an organisation’s data management infrastructure.</p>

<p>This session will be a brief signposting talk, with 30 minutes set aside for open Q&amp;A with the authors.</p>
